# Сонголтын туршилтын судалгаа

Бүтээгдэхүүний хувилбарын тоо (6/18) болон мэдээллийн хэмжээ (4/8 үзүүлэлт) сонголтын хэт ачаалалд (choice overload) хэрхэн нөлөөлөхийг 2×2 туршилтаар судлах онлайн судалгааны хуудас.

- `index.html`: оролцогчийн хуудас (`?s=<deployment id>`)
- `index.html?demo=1`: зохиомол өгөгдөлтэй жишээ
- `setup.html`: судлаачид зориулсан алхамчилсан заавар, холбоос шалгах, QR, зураг жигдлэх хэрэгсэл
- `apps-script/Code.gs`: судлаачийн Google Sheet-д тавих backend

## Ажиллах зарчим

1. Судлаач өөрийн Google Sheet-д бүтээгдэхүүн, үзүүлэлт, асуултаа оруулж, `Code.gs`-ийг Apps Script-д тавина.
2. "Тохиргоог шалгаж нийтлэх" цэс өгөгдлийг шалгаад, зургийг шингээсэн тохиргооны файл үүсгэнэ.
3. Apps Script-ийг Web app болгон нийтэлнэ (Execute as: Me, Who has access: Anyone).
4. Оролцогч хуудсыг нээхэд тохиргоо ачаалагдаж, дуусгасан болон одоо бөглөж буй оролцогч хамгийн цөөн нөхцөлд хуваарилагдана. Тохиргоо хуудаснаас нөхцөл тус бүрийн зорилтот тоо болон нээлттэй нөхцөлийг шууд удирдана.
5. Хариулт судлаачийн Google Sheet-ийн "Хариулт" хуудсанд мөр болж орно.

Энэ сайт өөрөө ямар ч өгөгдөл хадгалдаггүй. Бүх хариулт судлаачийн Google бүртгэлд үлдэнэ.

## Бүртгэгдэх хэмжүүр

Нөхцөл, сонгосон бүтээгдэхүүн ба байрлал, шийдвэр гаргах хугацаа, сонголт өөрчилсөн тоо, харсан картын тоо, харуулсан дараалал, төхөөрөмж, дэлгэцийн өргөн, нийт хугацаа, хуудас дахин ачаалсан тоо, асуулт бүрийн хариулт.
